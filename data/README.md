## Что уже собрано

### 1. Официальная статистика (Росстат, сборник «Регионы России — 2025»)
- Полный сборник: 22 раздела, 823 таблицы; выгружено 397 таблиц, содержащих строку «Саратовская область»
  (`rosstat/saratov_tables.txt`, `rosstat/saratov_tables.json`).
- Текстовые дампы всех разделов: `rosstat/Region_Pokaz_2025/txt/R_*.txt` — по ним можно находить любые показатели.

### 2. Рынок труда (вакансии)
- API «Работа в России» отдаёт **7 939** активных вакансий по региону (код 6400000000000).
- Ограничение API: `offset + limit ≤ 200` на запрос; фильтры `modifiedFrom/modifiedTo` возвращают HTTP 500.
  Поэтому выборка строится по ключевым словам профессий с дедупликацией по id (файлы `labor/vacancies.csv`, `labor/vacancies_raw.json`).
- Документация API сохранена в `trudvsem_api_docs.txt`.

### 3. Объекты экономики (OSM)
- Публичные зеркала Overpass из РФ большей частью недоступны; рабочее — `overpass-api.de`
  с User-Agent `overpass-turbo/3.0` (с браузерным UA сервер отдаёт 406).
- Запрос по всей области упирается в таймаут, а после серии запросов Overpass **заблокировал IP**
  (TCP-таймаут на всех зеркалах). Поэтому источник заменён на **выгрузку Geofabrik**:
  `russia/volga-fed-district-latest.osm.pbf` (0,77 ГБ) → `osm/volga-fed-district-latest.osm.pbf`.
- Разбор PBF — `../../.tools/parse_pbf.py` (библиотека `osmium`): объекты отбираются по тегам
  и фильтруются **по реальной границе области** (`osm/region_boundary.geojson`, получена из Nominatim),
  а не по прямоугольнику, поэтому объекты соседних регионов в выборку не попадают.
- Промежуточные попытки по координатной сетке лежат в `osm/_cache_07deg/` и в расчёт не идут.

### 3а. Банковский сектор
- Данные Банка России по Саратовской области взяты из того же сборника Росстата (раздел 20, табл. 20.9–20.17):
  число кредитных организаций и филиалов, вклады, кредиты. Отдельный справочник подразделений на сайте ЦБ
  больше не публикуется в машиночитаемом виде (`XML_branch.asp` отдаёт 404), `XML_bic.asp` содержит только
  название, БИК и ИНН — без адресов и регионов (708 записей по всей России).
  Физическое присутствие банков закрыто данными OSM (547 объектов с брендами).
- **ЕМИСС (fedstat.ru) доступен, но не использован:** все нужные показатели (ВРП, занятость, отраслевая
  структура, формы собственности, банковский сектор) есть в сборнике «Регионы России — 2025»,
  а машиночитаемый API ЕМИСС требует персонального токена.

### 4. Банковский справочник ЦБ
- `XML_bic.asp` доступен (windows-1251). Эндпоинты по подразделениям кредитных организаций отдают HTML — источник уточняется.

## Ограничения, о которых надо помнить

1. Вакансии — **выборка по ключевым словам**, а не полный массив (ограничение API). Долю покрытия считаем от 7 939.
2. OSM — краудсорсинговые данные: полнота по малым населённым пунктам заметно ниже, чем по городам.
3. Показатель «работники организаций по формам собственности» в сборнике приведён за 2010 и 2020 гг.
4. Данные Росстата — за 2023–2024 гг. (последние опубликованные), в работе нужно фиксировать дату отсечения.
