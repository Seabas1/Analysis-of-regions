# Ход работы (кратко)

**Задача.** Дать экономическое описание Саратовской области в трёх разрезах:
рынок денег — рынок труда — рынок товара; первичный — вторичный — третичный сектор;
государственный — частный — смешанный сектор. Основа — официальная статистика,
форма представления — презентация для доклада.

**Выбранная схема работы:** сначала собрать данные по каждому разрезу из открытых источников,
затем свести их в таблицы, перепроверить и только после этого оформлять выводы.

## Этапы

1. **Официальная статистика.** Скачали сборник Росстата «Регионы России. Социально-экономические
   показатели — 2025». Распаковали 22 раздела, перевели их в текст, нашли **397 таблиц**,
   содержащих строку «Саратовская область», и выбрали из них нужные показатели
   (табл. 1.1, 2.1, 2.3, 3.3–3.7, 4.6, 9.1–9.4, 10.1, 12.4, 12.7, 20.9–20.17).

2. **Рынок труда.** Обратились к API портала «Работа в России»: он показывает 7 939 активных
   вакансий по региону, но отдаёт не более 200 записей на запрос, а фильтры по датам не работают.
   Поэтому собрали выборку по 129 ключевым словам профессий с удалением дублей — **4 183 вакансии**
   (52,7% активных), 1 760 профессий, 1 119 работодателей.

3. **Объекты экономики (OSM).** Попытка работать через Overpass API: рабочее зеркало нашлось только
   с нестандартным User-Agent, запрос по всей области упирается в таймаут, а после серии запросов
   сервис заблокировал IP. Перешли на выгрузку Geofabrik: скачали PBF Приволжского федерального
   округа (0,77 ГБ), разобрали его библиотекой `osmium` и отфильтровали объекты **по реальной
   границе области** (получена из Nominatim), а не по прямоугольнику. Результат — **2 432 объекта**:
   1 576 магазинов, 310 банкоматов, 268 объектов услуг, 237 банков, 41 производство.

4. **Банковский сектор.** Машиночитаемый справочник подразделений Банка России снят с публикации
   (`XML_branch.asp` отдаёт 404), поэтому институциональную статистику взяли из раздела 20 того же
   сборника (данные Банка России: число кредитных организаций и филиалов, вклады, кредиты),
   а физическое присутствие банков — из OSM.

5. **Обработка.** Свели показатели по трём разрезам, привязали OSM-объекты к городам
   (по ближайшему населённому пункту — в OSM поле города почти не заполнено), посчитали топы
   профессий, сфер и работодателей.

6. **Проверка и оформление.** Пересчитали все производные величины, сверили результаты двух
   независимых источников по OSM, собрали презентацию из 15 слайдов с редактируемыми диаграммами
   и заметками докладчика, сделали PDF-версию.

## Проблемы и решения

| Проблема | Решение |
|---|---|
| В сборнике 823 таблицы в 22 файлах .docx | Автоматический разбор и поиск всех строк «Саратовская область» |
| Лимит API вакансий: `offset + limit ≤ 200` | Сбор по ключевым словам профессий с дедупликацией по id |
| Фильтры по датам в API вакансий дают ошибку 500 | Отказались, обошлись разбивкой по профессиям |
| Overpass блокирует браузерный User-Agent (406) | Указали User-Agent `overpass-turbo/3.0` |
| Overpass не выдерживает запрос по всей области | Перешли на выгрузку Geofabrik и разбор PBF |
| Overpass заблокировал IP за объём запросов | Источник заменён, работа продолжилась без потерь |
| HeadHunter API отвечает 403 | Заменён на портал «Работа в России» (Роструд) |
| Справочник подразделений ЦБ снят с публикации | Институциональная статистика — из раздела 20 сборника, присутствие банков — из OSM |
| Росстат не проходит проверку SSL-сертификата | Обход проверки сертификата для официального сайта |
| В OSM не заполнено поле города | Привязка объекта к ближайшему городу области (27 городов, 96% объектов ближе 30 км) |

## Что получилось на выходе

- сводка показателей по трём разрезам с указанием таблиц-источников;
- таблица объектов экономики по городам области;
- выборка вакансий и топы профессий, сфер, работодателей;
- презентация на 15 слайдов (.pptx) и её PDF-версия;
- журнал источников и ограничений по каждому набору данных.
