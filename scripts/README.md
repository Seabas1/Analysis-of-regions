# Скрипты проекта

Пайплайн разделён по слоям: **сначала сбор данных, затем аналитика по каждой сфере**.

```
scripts/
  steps/            ← общий слой: скачать и разобрать данные (нужен всем сферам)
  overview.py       ← ОБЩАЯ СВОДКА: регион в цифрах, структура экономики
  finance.py        ← ФИНАНСОВЫЙ СЕКТОР
  labor.py          ← РЫНОК ТРУДА
  goods.py          ← РЫНОК ТОВАРОВ И УСЛУГ
  make_presentation.py
  make_presentation_plain.py
```

## Почему сбор данных общий, а аналитика раздельная

Выгрузка OSM (775 МБ) и сборник Росстата нужны сразу нескольким сферам: банки и магазины лежат
в одном PBF, а разделы сборника — в одном архиве. Поэтому скачивание и разбор вынесены в
`steps/` и выполняются один раз. Аналитика, наоборот, у каждой сферы своя: у неё свои источники,
свои показатели и свой вывод.

## Слой сбора и парсинга (steps/)

| Скрипт | Что делает | Вход → выход |
|---|---|---|
| `download_rosstat.py` | качает сборник «Регионы России — 2025» | сайт Росстата → `data/rosstat/*.rar` |
| `rosstat_docx_to_text.py` | переводит 22 раздела .docx в текст | `.rar` → `txt/R_*.txt` (823 таблицы) |
| `rosstat_extract_region.py` | отбирает таблицы со строкой региона: сохраняет номер таблицы, шапку и строки региона | дампы → `saratov_tables.json` (476 таблиц) |
| `get_region_boundary.py` | полигон границы области | Nominatim → `region_boundary.geojson` |
| `download_osm_pbf.py` | выгрузка Приволжского ФО | Geofabrik → `*.osm.pbf` (775 МБ) |
| `parse_osm_objects.py` | разбор PBF: отбор по тегам и фильтр по границе | PBF → `objects.csv` (2 432) |
| `assign_cities.py` | привязка объектов к ближайшему городу | `objects.csv` → `objects_by_city.csv` |
| `parse_vacancies_trudvsem.py` | сбор вакансий через API | API → `vacancies.csv` (4 183) |
| `rosstat_values.py` | **читает числа из выборки сборника** по номеру таблицы, году и подписи столбца | `saratov_tables.json` → значения |

## Аналитика по сферам

| Скрипт | Берёт | Считает |
|---|---|---|
| `overview.py` | табл. 1.1, 1.7, 2.1, 2.3, 3.6, 9.2, 9.4, 12.4, 12.7 | площадь, население и его динамика, занятость, ВРП и ВРП на душу, инвестиции, секторы экономики, формы собственности |
| `finance.py` | табл. 20.9–20.14 + `objects_by_city.csv` | институты и филиалы, вклады, кредиты, подушевые вклады, Сбербанк и его доля, размещение и бренды |
| `labor.py` | `vacancies.csv` + табл. 1.1, 4.6 | распределение зарплат, топы профессий, сферы с медианами, опыт, концентрация работодателей |
| `goods.py` | `objects_by_city.csv` + табл. 1.1 | форматы магазинов, сети, производства, территории, денежный масштаб |

Каждый сферный скрипт печатает свой блок отчёта и пишет таблицы в `analiz/`.

## Как читаются числа Росстата

Сферные скрипты **не хранят чисел у себя**. Каждое значение адресуется в сборнике:

```python
dep = rv.require(t, "20.10", year=2025, label="физических", part=1)
```

Это означает «таблица 20.10, 2025 год, вклады физических лиц, вторая часть таблицы».
`rosstat_values` находит столбец по строке годов в шапке и подписям столбцов, а значение берёт
из строки «Саратовская область». Если столбец не найден — скрипт падает с ошибкой, а не
подставляет пустое значение.

Две тонкости, из-за которых понадобилась нормализация подписей:
- в сборнике слова разорваны переносами и двойными пробелами («Сельское, лесное  хозяйство»);
- встречаются опечатки — например, «Обеспечение электрическ**ое** энергией» вместо
  «электрической», поэтому поиск идёт по устойчивым фрагментам.

## Порядок запуска

```bash
pip install -r requirements.txt

# 1. Сбор данных (один раз)
python scripts/steps/download_rosstat.py
python scripts/steps/get_region_boundary.py
python scripts/steps/download_osm_pbf.py
python scripts/steps/parse_vacancies_trudvsem.py
python scripts/steps/rosstat_docx_to_text.py
python scripts/steps/rosstat_extract_region.py
python scripts/steps/parse_osm_objects.py
python scripts/steps/assign_cities.py

# 2. Аналитика по сферам
python scripts/overview.py
python scripts/finance.py
python scripts/labor.py
python scripts/goods.py

# 3. Презентация (вне пайплайна, из готовых таблиц)
python scripts/make_presentation.py
```

Все скрипты идемпотентны: повторный запуск использует уже скачанные файлы. Пути вычисляются от
расположения скриптов, поэтому проект работает из любой папки.

Шаблон СПбГУ для презентации лежит вне репозитория; его путь задаётся переменной окружения
`SPBU_TEMPLATE`.
