# Анализ экономики Саратовской области

Учебный проект: экономика региона разбирается по трём блокам — **финансовый сектор, рынок труда,
рынок товаров и услуг**. Данные собираются скриптами из открытых источников, затем считаются
сводные показатели, на их основе строится презентация.

Подход инженерный: у каждого показателя есть источник и скрипт, которым он получен; ограничения
источников не скрываются, а фиксируются.

## Что получилось

| Блок | Ключевые результаты |
|---|---|
| Финансовый сектор | 4 кредитные организации и 3 филиала (было 10 и 66 в 2011 г.); вклады 585,1 млрд ₽ (+в 6 раз); 51,8% вкладов населения — в Сбербанке; 547 объектов размещения из OSM |
| Рынок труда | 4 183 вакансии из 7 939 активных (52,7%); медиана предлагаемой зарплаты 38 000 ₽ против 58 626 ₽ средней фактической; 88,5% вакансий на опыт 0–1 год |
| Рынок товаров и услуг | 1 576 магазинов, 268 объектов услуг, 41 производство; промышленность 1 039,3 млрд ₽ против розницы 648,5 млрд ₽; 63,5% магазинов — в трёх городах |

## Структура репозитория

```
scripts/           скрипты пайплайна: сбор → парсинг → анализ (+ сборка презентации)
data/              собранные данные и производные таблицы
  rosstat/         выборка из сборника Росстата со строкой региона
  labor/           вакансии с портала «Работа в России»
  osm/             объекты экономики из OpenStreetMap
analiz/            сводные таблицы: топы профессий, сферы, объекты по городам
assets/            знак СПбГУ и шрифт Open Sans для сборки презентации
*_презентация_СПбГУ.pptx / .pdf    презентация на официальном шаблоне СПбГУ (19 слайдов)
Техническое_описание.md            пайплайн, скрипты, результаты, ограничения
Текст_для_защиты.md                речь по слайдам, версия на 5 минут, вопросы и ответы
Разбор_*.md                        подробный разбор каждого блока
Ход_работы.md                      краткое описание хода работы
```

## Как запустить

Пайплайн линейный, оркестратора нет — скрипты запускаются по порядку.

```bash
pip install -r requirements.txt

# 1. Сбор
python scripts/download_rosstat.py          # сборник «Регионы России — 2025»
python scripts/get_region_boundary.py       # полигон границы области
python scripts/download_osm_pbf.py          # выгрузка OSM, 775 МБ
python scripts/parse_vacancies_trudvsem.py  # вакансии, ~5 минут

# 2. Парсинг
python scripts/rosstat_docx_to_text.py      # 22 раздела сборника в текст
python scripts/rosstat_extract_region.py    # 397 таблиц со строкой региона
python scripts/parse_osm_objects.py         # объекты из PBF, ~30 минут
python scripts/assign_cities.py             # привязка объектов к городам

# 3. Анализ
python scripts/aggregate.py                 # сводные таблицы в analiz/

# Оформление (вне пайплайна)
python scripts/make_presentation.py         # презентация по официальному шаблону
```

Скрипты идемпотентны: повторный запуск использует уже скачанные файлы, поэтому прерывание работы
не приводит к потере данных. Пути определяются от расположения самих скриптов, поэтому проект
можно клонировать в любую папку.

**Сборка презентации** требует шаблон СПбГУ — он лежит вне репозитория. Путь задаётся переменной
окружения `SPBU_TEMPLATE`; без неё подставляется путь по умолчанию из скрипта.

## Чего нет в репозитории

- **Примера (чужой ВКР)** — папка `_образец/` не публикуется.
- **Крупных файлов**, которые восстанавливаются скриптами: выгрузка OSM (775 МБ), архив и PDF
  сборника Росстата (~50 МБ), распакованные разделы .docx, текстовые дампы, сырые ответы API
  вакансий (15 МБ). Всё это скачивается и создаётся заново запуском скриптов этапов 1–2.
- **Файлов шаблона СПбГУ** — фирменная графика берётся из шаблона кафедры, он не распространяется.

## Источники данных

| Источник | Что взято |
|---|---|
| Росстат, «Регионы России. Социально-экономические показатели — 2025» | основные показатели, население, труд, ВРП, инвестиции, организации, банковский сектор (раздел 20 — по данным Банка России) |
| Портал «Работа в России» (trudvsem), открытые данные | вакансии: профессия, зарплата, работодатель, адрес, требования |
| OpenStreetMap (выгрузка Geofabrik) | объекты экономики: банки и банкоматы, производства, услуги, магазины |

## Ограничения

1. Выборка вакансий — 52,7% активных (ограничение API в 200 записей на запрос), смещена к профессиям
   из списка ключевых слов.
2. OpenStreetMap — краудсорсинговые данные: розничные точки размечены хорошо, промышленные площадки —
   плохо; адрес улицы указан у 18,9% объектов.
3. Показатели в текущих ценах, без дефляции.
4. Таблица 20.9 считает филиалы, а не дополнительные офисы и кассы.
5. ВРП публикуется с лагом в один год: последние данные — за 2023 г.

Подробнее — в `data/README.md` (журнал сбора данных) и `Техническое_описание.md`.
